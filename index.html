Personal Google integration

Desktop OAuth

A personal Google OAuth client for owner-operated desktop and self-hosted tools, including a personal Hermes assistant.

What this application does

Desktop OAuth lets a connected tool request permission to call Google APIs on the account owner's behalf. The tool uses that access to carry out the Google-service tasks the owner requests, within the permissions granted during Google authorization.

This is a personal integration, not a public account-management service. This static website provides application information and a privacy policy; it does not run the assistant, handle Google sign-in callbacks, or collect OAuth tokens.

Permissions and control

Review the exact services and permissions on Google's consent screen before authorizing a connected tool. A tool's configuration and your instructions determine which authorized features it uses. This website does not request additional Google permissions.

You can revoke access at any time in your Google Account connections. Revocation does not automatically delete copies already stored by a connected tool.

Privacy and support

Read the Desktop OAuth privacy policy for information about authorized data, connected tools, storage, and revocation.

For questions about these pages, use the project issue tracker. Never post credentials, tokens, or private Google data in a public issue.
