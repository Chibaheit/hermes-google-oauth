Desktop OAuth

Privacy policy

Effective October 18, 2026. This policy describes this static website and the intended use of the Desktop OAuth personal integration.

Scope and purpose

Desktop OAuth is used with owner-operated desktop and self-hosted tools, including a personal Hermes assistant. Access to Google services requires the account owner's authorization. This website itself does not provide an OAuth callback endpoint, request Google permissions, or receive Google account data or tokens.

Google data accessed by connected tools

The permissions presented by Google during authorization determine the account information and service data a connected tool may access. The tool's implementation, configuration, and the user's instructions determine which authorized data it actually reads or changes.

Authorized access is intended only to perform the personal Google-service tasks the user requests. This site does not assert that every Google permission is needed or granted, and it does not expand an existing authorization.

Processing and third parties

Google processes authorization requests and the resulting API calls. Connected tools process authorized data in their configured local or self-hosted environment. Depending on the requested task and configuration, selected information may also be sent to configured hosting, tool, or AI-model providers. Review those settings and the providers' policies before authorizing access or requesting a task involving private data.

Google user data must be used only for the authorized, user-requested functionality, not sold, used for advertising, or used to train generalized artificial intelligence or machine-learning models. The operator must choose provider settings consistent with these restrictions.

Use and transfer of information received from Google APIs must adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

This public website and repository are not storage locations for Google credentials, tokens, account data, or task output. Such information may be retained by a connected tool in its configured environment. Actual storage protections and retention depend on that tool and its configuration; this website does not make a claim about a particular installation's encryption or deletion schedule.

Limit access to that environment, keep credentials out of public repositories and logs, and retain only the information needed for the requested tasks. Review any configured third-party provider's retention controls separately.

Revocation and deletion

Revoke Google access through your Google Account connections. This prevents further access using the revoked authorization, but does not itself delete previously stored information.

To delete stored credentials, cached data, logs, or task output, remove them from the connected tool's environment or contact its operator. Copies sent to a configured provider are subject to that provider's deletion process.

Website hosting

These pages are hosted on GitHub Pages. They contain no application analytics, advertising, forms, third-party scripts, or embedded sign-in flow. GitHub may process ordinary request metadata when serving the site under the GitHub General Privacy Statement.

Contact and updates

For questions about this policy, open an issue in the project repository without including private account details. For a private data or deletion request, contact the operator of the connected tool through an existing private channel.

Changes to these pages are recorded in the public repository. The effective date above identifies this policy version.
