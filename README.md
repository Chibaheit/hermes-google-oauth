# Desktop OAuth public pages

Application information and privacy policy for the personal **Desktop OAuth**
Google OAuth client. No application code, OAuth credentials, tokens, account
data, or private configuration belongs in this repository.

## Site

- Home: <https://chibaheit.github.io/hermes-google-oauth/>
- Privacy: <https://chibaheit.github.io/hermes-google-oauth/privacy.html>

GitHub Pages publishes the repository root on `main`. The pages use plain HTML
and CSS, with no build dependencies or client-side scripts.

The site documents intended personal use. It does not implement OAuth, change
requested permissions, or certify the configuration of a connected tool. Keep
the policy consistent with actual data handling if that integration changes.

## Google configuration

Use the home and privacy URLs above in Google Auth Platform's Branding page.
The corresponding authorized domain is `chibaheit.github.io`.

An accessible site does not itself establish Google Search Console ownership
or complete Google brand or data-access verification. Those are separate steps
if required by Google.
